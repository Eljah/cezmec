# Cezmec — язык пространства

Open project for crowdsource for spatial relation in all world's languages.

Рабочий прототип текстового корпуса: **Java 17+, Maven, Spring Boot 4.1.1**, встроенная файловая H2; браузерный интерфейс на обычных HTML/CSS/JavaScript, анимации SVG. Для запуска не нужны Node.js, отдельный фронтенд-сервер, GIF-файлы или облачные сервисы.

## Запуск

```sh
git clone --branch feature/spatial-crowdsource-20261007 https://github.com/Eljah/cezmec.git
cd cezmec
mvn clean verify
java -jar target/cezmec-0.1.0.jar
```

Открыть **http://localhost:8080**. Нужны JDK 17 или новее и Maven 3.6.3+. В IntelliJ открыть `pom.xml`, установить Project SDK 17+, запустить `CezmecApplication`. В Windows команды Maven и Java те же. База сохраняется в `./data/cezmec.mv.db` относительно рабочей папки. Не запускайте два экземпляра над одним файлом базы.

Альтернативно: `mvn spring-boot:run` или `docker compose up --build`.

## Что реализовано

- **72 версионированных стимула:** 36 ситуаций × две перестановки цветов. Вход и выход, внутри и сквозь, приближение и достижение, сверху и снизу, контакт и опора, масса и полость, обход, перенос, толкание, тяга, открывание и закрывание прохода.
- SVG-анимации: пауза, шкала времени, скорость, повтор. При системной настройке reduced motion автоматическое воспроизведение выключено. G/R и пунктир дублируют цвет.
- Русский, татарский, цезский и английский в стартовом каталоге; добавление языков/диалектных вариантов с собственными словами, шаблоном и направлением письма. Цезские `G`/`R` — **не переводы**.
- До 10 альтернатив за отправку. Морфологические формы внутри цветных меток можно менять: `{G:объект} {R:субъектка} керә`. Допускаются явно отмеченные опущенные участники, свободный порядок, перевод, глосса, диалект и самооценка владения языком.
- Вес 0–100 для каждой формулировки. Своя повторная оценка заменяет предыдущую; отображаются среднее и число оценок. Это не объективная вероятность правильности.
- Серверное сохранение, локальные черновики, безопасный текстовый вывод, CSRF, удаление своего ответа, жалобы и API модератора.
- Экспорт JSON выбранного языка с идентификатором/версией сцены и отметками просмотра примеров/чужих ответов. Примеры из задания исключены из статистики и экспорта.

## Цвета и роли

В исходном задании названия «субъект/объект» противоречат цветам в примерах. Поэтому **G всегда зелёное тело, R всегда красное**, а описывать предлагается G. Предзаполненные русские имена намеренно сохранены как в примерах: G — «Объект», R — «субъект». Их можно заменить перед созданием заготовки или прямо в фразе. Система не объявляет G грамматическим подлежащим, агенсом, движущимся телом или носителем определённого падежа.

Для `enter-g` движется зелёный шар; для `enter-r` движется красный шар, но описание запрашивается о зелёном вместилище. «Впускает» и «вбирает» не автоматически эквивалентны простому входу: отдельно фиксируется интерпретация и предусмотрены дополнительные сцены с открывающимся проходом и физическим воздействием.

Описание исследователя и чужие ответы скрыты до явного раскрытия. Сцены — пилотный набор, **не валидированный универсальный перечень значений**. Подробнее: [методика и цезский язык](docs/METHODOLOGY.md), [API и эксплуатация](docs/OPERATIONS.md).

## Проверки

```sh
mvn -B -ntp verify
node --test tests/geometry.test.js
npm install --ignore-scripts
npx playwright install chromium
npm run test:e2e
```

Последняя команда требует предварительно собранный JAR. Браузерные проверки запускают отдельную H2 в памяти. GitHub Actions собирает приложение, выполняет Java-, геометрические и браузерные проверки; артефакт `cezmec-build` содержит JAR, исходники, отчёты и снимки экрана. Точные результаты конкретного коммита — во вкладке Actions, а не обещание вечной успешности этой инструкции.

## Границы прототипа

Это сбор **текстовых записей**, без микрофона и аудио. Интерфейс пока русскоязычный, сами ответы поддерживают Unicode и RTL. Cookie обозначает браузер, не проверенного человека: очистка cookie позволяет получить новую идентичность, а утрата cookie лишает возможности редактировать собственные записи. Нет автоматической проверки переводов, нормативной регистрации языковых кодов, экспертного утверждения ответов, учётных записей и защиты от согласованной накрутки. Публичное развёртывание требует HTTPS, внешнего ограничения запросов, резервного копирования и организационного решения о лицензии корпуса; добавление кода в GitHub само по себе сайт не размещает.
